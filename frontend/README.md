# React + vite

# Initialize All Npm packages

- Npm install

# Run the app

- npm run dev

## Features

- Request lifecycle: loading, success, empty, error, retry
- Case-insensitive search by title (original API data is never modified)
- Pagination: 10 posts per page, Previous/Next disabled at the ends
- Pagination resets to page 1 when the search query changes
- Request safety: no duplicate requests, no stale responses, Retry spam guard
